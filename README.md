# HealthCare Analysis

## Project Overview

This project analyzes hospital patient survey data to explore hospital
performance, survey response rates, completed surveys, geographic
distribution, and patterns across hospitals, cities, and counties.

The project was completed as part of my Data Engineering Academy studies
and was designed to practice the complete analytical workflow:
understanding the business objective, examining the available data,
identifying data-quality limitations, developing analytical questions,
creating measures, and communicating findings through Power BI.

## Project Objectives

The analysis focuses on:

-   Hospital survey response rates
-   Number of completed surveys
-   Differences in survey participation across hospitals and counties
-   Hospital distribution across cities
-   Geographic patterns using hospital/location data
-   Patient survey star-rating information where supported by the
    provided data

## Tools Used

-   Python / Pandas
-   Power BI
-   DAX
-   Data modeling
-   Data visualization
-   Git / GitHub

## Data Limitations

The analysis represents the data provided for this project and should
not be interpreted as a complete representation of all hospitals in the
United States.

During the analysis, limitations were identified in the available
hospital, geographic, and patient survey information. Therefore,
findings are reported as evidence observed within the provided dataset
rather than generalized to the entire U.S. hospital population.

The patient survey star-rating information was also retained and
reported as an observed finding, but it is not used to establish a
comprehensive national hospital ranking because the available data does
not provide sufficient coverage for that conclusion.
